[abstract]
--
GroovyConcurrentUtils (GCU) is a Groovy library of concurrency building blocks for the JVM:
virtual-thread pools, promises, dataflow variables, a stream wrapper, reactive data, actors
and agents, and -- built on those -- TaskGraph, a DSL and engine for running graphs of tasks.
It also carries the platform services those capabilities share: configuration loading,
security controls and clustering.

This book describes what each capability is for, how it is used and what it guarantees. It
describes the library as it stands. The history of how it got here is in `CHANGENOTE.md` and
the archive (see <<app-history>>).
--

[preface]
== About This Book

*What it covers.* One chapter per capability area of the library, grouped into parts. The
core concurrency chapters come first because everything else is built on them: TaskGraph
runs its tasks on the pools, hands results around as promises, and wires task outputs to
task inputs through dataflow. Read Part II before Part V if you want to understand why
TaskGraph behaves as it does; go straight to Part V if you only want to build workflows.

*Who it is for.* Developers using GCU directly, and developers building on top of it. The
MCP agentic-workflow server is the largest consumer of TaskGraph, and its own book assumes
this one.

*How it is maintained.* This book is edited in place. A change to how a capability works
updates the chapter that describes it; the story of the change goes into `CHANGENOTE.md`,
never into a new chapter here. The version in the header is the library version the text
was last checked against.
